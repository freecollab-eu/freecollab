# FreeCollab browser demo

This branch serves the account-free sample showroom from FreeCollab 0.13.0.
Messages, tasks, documents, setup checklists and appearance work locally in your browser.
Changes reset on reload. There is no shared account, collaboration API, real provider
authorization, server storage or encrypted multi-user session in this demo.

The complete product source and self-hosting instructions are on [main](https://github.com/freecollab-eu/freecollab).
The generated page includes the original software and font license notices.
